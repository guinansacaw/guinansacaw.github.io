Descripción

En este proyecto, se transformó datos brutos de un supermercado en conocimiento para toma de decisiones, combinando SQL, Power BI y Machine Learning para extraer insights clave. Desde el análisis financiero hasta la identificación de patrones de compra, se generaron dashboards interactivos y se aplicó Market Basket Analysis para optimizar estrategias de venta y maximizar ingresos.

  • Dashboards en Power BI con métricas clave, tendencias y segmentaciones.
  • Reglas de Asociación para descubrir productos que se compran juntos y mejorar promociones.
  • KPIs Financieros y de Clientes para entender el rendimiento.

📊 ¿El resultado? Una solución analítica integral que permite decisiones basadas en datos, mejora la rentabilidad y anticipa el comportamiento del consumidor. 🚀
