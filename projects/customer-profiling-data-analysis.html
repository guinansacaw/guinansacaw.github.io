Aprendizaje no supervisado: Segmentación de Clientes

Este proyecto de análisis de datos incluye diversas tareas realizadas en Python como:

  • Limpieza de datos: Identificación y eliminación de valores nulos, así como la normalización de variables.
  • Selección de características: Se seleccionaron las variables más relevantes para el modelo.
  • Aplicación de técnicas de clustering: Implementación del algoritmo K-Means para segmentar a los clientes.
  • Validación del modelo: Evaluación de la calidad de los clusters mediante el uso de métricas como el Silhouette Score.
  • Visualización: Se utilizaron gráficos como el PCA (Análisis de Componentes Principales) y TSNE para visualizar los clusters en un espacio reducido.

Acerca del conjunto de datos

Este proyecto utiliza el conjunto de datos South German Credit proporcionado por el UCI Machine Learning Repository (2020), bajo licencia adecuada para uso público y académico. Para más información, consulta el DOI en el siguiente link.

Resumen

En este proyecto, abordamos la segmentación de clientes utilizando técnicas de aprendizaje automático no supervisado, centrándonos en la aplicación del algoritmo K-Means. El conjunto de datos, derivado de un contexto bancario, pasó por pasos de preprocesamiento como la normalización, la reducción de dimensionalidad utilizando Análisis de Componentes Principales (PCA) y el manejo de valores atípicos para asegurar la calidad de los datos. La calidad del agrupamiento se evaluó utilizando el índice de Silhouette en múltiples configuraciones de clusters. Los resultados revelan clusters bien definidos que destacan perfiles de clientes distintos, útiles para diversas aplicaciones como estrategias de marketing. El estudio demuestra la efectividad de K-Means en la identificación de patrones en los datos de clientes, ofreciendo una base para procesos de toma de decisiones basados en datos.

Introducción

El objetivo principal es identificar clusters que representen a grupos con perfiles similares de clientes. Para lo cuál, se realizó un preprocesamiento de los datos, que incluyó la normalización de variables, la reducción de dimensionalidad mediante PCA, y la evaluación de la calidad del clustering con la métrica Silhouette. Los resultados obtenidos nos permiten ver como los clientes pueden ser agrupados y etiquetados para la futura toma de desiciones.

Descripción del Dataset

El dataset SouthGermanCredit fue utilizado para el proyecto y contiene información financiera de varios clientes. Existen 1000 instancias que fueron divididas en conjuntos de entrenamiento y prueba con una proporción de 80:20, respectivamente. De las 21 variables, se tomaron 20 características entre variables numéricas y categóricas. La variable objetivo es el riesgo de crédito, clasificado en bajo y alto.

  • Pre-procesamiento de Datos

    Se realizó un análisis para detectar valores faltantes, y se confirmó que no existían valores nulos en el conjunto de datos. Posteriormente, las variables categóricas fueron codificadas utilizando las técnicas de One-Hot Encoding y LabelEncoder, lo que expandió el número de características a un total de 72 columnas. Además, las variables numéricas seleccionadas, como duración, monto y edad, fueron escaladas mediante la técnica de normalización StandardScaler, garantizando una adecuada preparación de los datos para los algoritmos de machine learning.

  • Transformaciones Aplicadas

    Se aplicó el Análisis de Componentes Principales (PCA) únicamente para graficar los resultados del clustering y facilitar su interpretación. Asimismo, se utilizó la técnica t-Distributed Stochastic Neighbor Embedding (t-SNE) con el objetivo de visualizar las relaciones y agrupamientos en un espacio de menor dimensionalidad, sin que estas técnicas se emplearan para reducir las dimensiones de los datos originales.

Metodología

  • Pre-procesamiento de Datos

    Antes de introducir los datos en el modelo, se realizó un preprocesamiento para garantizar la calidad y consistencia del análisis. En primer lugar, se llevó a cabo una revisión de los datos faltantes y se confirmó que no existían valores nulos. Las variables numéricas, que presentaban un sesgo positivo hacia la derecha, fueron transformadas mediante la raíz cuadrada para mejorar su distribución. Las variables categóricas se codificaron utilizando las técnicas de One-Hot Encoding y LabelEncoder, mientras que las variables numéricas y ordinales, como duración de empleo, tasa de la cuota, residencia actual y número de créditos, fueron escaladas utilizando StandardScaler. Además, se detectaron outliers en las variables de monto del crédito y edad del cliente empleando boxplots y z-scores; dado que los valores atípicos no eran extremos, fueron tratados igualmente con StandardScaler. Por último, se realizó un análisis de correlación para identificar relaciones significativas entre las variables.

  • Implementación y Configuración de Modelos de Clustering

    Se evaluaron tres enfoques principales. En primer lugar, se utilizó el algoritmo K-Means, ajustando diferentes valores de k para optimizar el número de clusters y garantizar una segmentación efectiva. En segundo lugar, se aplicó Agglomerative Clustering, explorando diversos valores de hiperparámetros como el método de enlace (linkage), la métrica de distancia y el número de clusters (k). Por último, se implementó el algoritmo DBSCAN, probando distintas configuraciones del parámetro eps para identificar el mejor desempeño en la agrupación de datos.

  • Evaluación y Validación de los Modelos

    La evaluación y validación de los modelos se calculó el Silhouette Score para cada modelo, lo que permitió medir la cohesión y separación de los clusters, identificando qué tan bien definidos estaban en el espacio de características. Además, se empleó validación cruzada mediante el método de bootstrap, lo que permitió analizar el rendimiento y la estabilidad del clustering a través de múltiples muestras, asegurando la robustez de los resultados obtenidos.

  • Etiquetado de Clusters

    Finalmente, el modelo mejor evaluado (K-means) fue seleccionado y se analizó los clusters con gráficos de coordenadas paralelas y estadísticas descriptivas. El análisis permitió etiquetar a cada cluster al poder interpretar el comportamiento de los grupos de clientes.

Resultados y Discusión

Rendimiento de los Modelos

  • K-Means: El modelo de K-Means con k = 5 clusters fue el que mejor rendimiento presentó, con un Silhouette Score promedio de 0.075 en la validación cruzada por bootstrap. Este valor, aunque es bajo, muestra una clara superioridad frente a los otros modelos.
  • Agglomerative Clustering: Aunque este modelo también fue capaz de formar clusters con una separación aceptable (Silhouette Score promedio de 0.052), los resultados fueron inferiores a los obtenidos con K-Means.
  • DBSCAN: Este modelo no logró formar clusters significativos debido a la densidad variable de los datos, lo que resultó en un bajo rendimiento general.

Reducción de Dimensionalidad y Visualización

Las técnicas de reducción de dimensionalidad como PCA y T-SNE se emplearon para visualizar la estructura de los datos en un espacio de menor dimensión. Las Figuras 1 y 2 muestran la proyección bidimensional de los clusters obtenidos: Como se puede observar, los clusters formados por K-Means y Agglomerative Clustering están bien definidos en los gráficos. Para la evaluación del modelo, se realiza la validación cruzada, como muestra la Figura 3, donde se observa un mejor rendimiento de Silhouette Scores del modelo K-Means.

Discusión de los Resultados

Los resultados del clustering sugieren una segmentación clara de las características de los clientes, que permite enfocarse en sus distintas necesidades:

  • Segmentación de clientes: Los clusters identificados pueden utilizarse para desarrollar estrategias de marketing personalizadas, ajustando las ofertas y productos financieros a las necesidades específicas de cada grupo.
  • Gestión del riesgo: Al identificar perfiles de alto y bajo riesgo, las instituciones financieras pueden tomar decisiones más informadas sobre la concesión de créditos.
  • Optimización de recursos: La segmentación también permite una asignación más eficiente de los recursos de la empresa, enfocando esfuerzos de retención y adquisición en los segmentos de clientes más rentables.

Conclusión

Este proyecto tuvo como objetivo utilizar técnicas de clusterización para obtener patrones, tendencias y segmentar clientes de la base de datos SouthGermanCredit. Tras el análisis de varios modelos el algoritmo K-Means con 5 clusters fue seleccionado como el más adecuado, ya que proporcionó la mejor combinación de separación entre clusters, como lo demuestran los valores del Silhouette Score.

Los resultados del clustering revelaron cinco segmentos de clientes con características distintas, por tanto, existen patrones claros en los datos que permitan mejorar la toma de decisiones. El proyecto también destacó la importancia del preprocesamiento de datos, (la normalización y la reducción de dimensionalidad). El uso de visualizaciones como gráficos de coordenadas paralelas y PCA - TSNE ayudó a validar y entender mejor la estructura de los clusters.

Para futuros trabajos, sería interesante explorar otras técnicas de clustering que puedan mejorar la identificación de subgrupos dentro de los clusters formados. Finalmente, la implementación de estos resultados en un modelo predictivo para la aprobación de créditos sería un buen paso para evaluar la segmentación realizada.
